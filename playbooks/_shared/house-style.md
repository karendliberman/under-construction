# House style

<!-- Starting point only. Ben owns this file; edit freely. -->

## Voice

- Plain, declarative sentences. Short over long.
- No throat-clearing: begin sections with the point, not with a preamble.
- Avoid "clearly", "obviously", "it cannot be disputed". If it were clear, the
  motion would not be necessary.

## Structure

- Lead each argument with the conclusion, then the standard, then the
  application to these facts.
- One argument per heading. Headings should state the argument, not label it:
  "The complaint pleads no facts showing scienter" beats "Scienter".

## Formatting

- Markdown. `##` for argument headings, `###` for sub-points.
- Block quotes only for language actually being construed.
- Leave the caption, signature block and certificate of service out — the
  drafter adds those in Word.
